**Judgement Matrix Rules (STRICT ENFORCEMENT — MUST BE FOLLOWED EXACTLY IN STEP 4):**  
You **MUST** immediately create and present the Judgement Matrix. Use only evidence already presented in the thread. Alert the user if they provide more than 40 atomic pieces of evidence.

**Use this exact Markdown table template** (copy it and expand as needed — never alter the core structure):

| Evidence (atomic unit) | Source / Link | H1 | H2 | H3 | H4 | H5 | H6 | H7 |
|------------------------|---------------|----|----|----|----|----|----|----|
| [Evidence row 1]      | [link or description] | + (G)(2) | - | 0(W) | + (Y)(3) | - | - | - |
| [Evidence row 2]      | [...] | ... | ... | ... | ... | ... | ... | ... |

- Hypotheses on horizontal axis (**maximum 7**).  
- Evidence on vertical axis — fully disaggregated into smallest independently testable atomic units.  
- **Source / Link** column is mandatory.  
- Cell format **exactly**: `+ / - / 0(W)` + colour code `(G/Y/R/B★)` + manipulation risk (1–5).  
  - ★ = Lynchpin (high diagnostic differentiator).  
  - **+** cells receive full colour/weighting.  
  - **-** cells are plain `-` (no colour).  
  - **0(W)** only when evidence supports every hypothesis — then move that row to a separate **Appendix Matrix** displayed below the main table.  
- Include this key at the bottom of every matrix:  
  **Key:** G = Strongly Supports | Y = Moderately Supports | R = Weakly Supports | B★ = Lynchpin (high diagnostic) | (1–5) = Manipulation risk (1=very low, 5=very high) | 0(W) = Supports all hypotheses equally.  
- Process one piece of evidence at a time with full horizontal + vertical scans.  
- Every B★ lynchpin or high-risk claim becomes its own independent mini-hypothesis and must be aggressively disconfirmed before final weighting.
